# Журнал изменений

Номер версии имеет вид `vX.Y.Z[t] Name`:

- **X** — основная версия. Остаётся 0, пока сайт в разработке; 1 — первая полная версия (см. ROADMAP.md).
- **Y** — крупная возможность. Только такие версии получают название (Name) на английском: v0.1 Senate, v0.2 Duma, v0.3 Status. Название относится ко всей ветке v0.Y.
- **Z** — доработки и исправления внутри ветки; своего названия не получают (v0.3.1, v0.3.2).
- **t** — техническая версия: меняется только репозиторий (журнал изменений, план, теги, инструменты), а код сайта остаётся прежним. На сайте при этом продолжает отображаться номер последней нетехнической версии.
- **a, b, c…** — дополнительные технические версии к той же версии получают буквенные индексы после t: v0.3.2t, v0.3.2ta, v0.3.2tb.

Версии, загруженные на GitHub, отмечены тегами (`git tag`).

- При выделении федерального округа в центре подковы пишется его полное название в 2 строки;
- На ползунке подпись числа регионов и мест для новых территорий снова выводится в той же строке через интерпункт.
